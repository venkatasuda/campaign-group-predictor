# Optional dependencies - stronger models, richer explanations, experiment tracking.
#
# Every import of these is guarded in the source, so the project trains, serves and
# passes its tests without them:
#
#   * catboost / lightgbm / xgboost  -> the model zoo silently shrinks to
#     logistic regression, random forest, HistGradientBoosting and the MLP
#   * shap                           -> explainability falls back to permutation
#     importance, which is model-agnostic and always available
#   * mlflow                         -> src/tracking.py degrades to a no-op; the artifact
#     and metrics.json are still written, but no run history is recorded
#
# On mlflow specifically. It was previously installed ad hoc and declared nowhere, which is
# the worst of both states: the project documents experiment tracking as a feature, and
# anyone cloning it got a silent no-op instead. The graceful degradation was doing its job
# so well that the missing dependency produced no symptom.
#
# It is optional rather than core because tracking must never be able to fail a training
# run - but optional means "declared and skippable", not "undeclared".
#
# They are separated from requirements.txt because these packages are the most likely
# to lack a prebuilt wheel for a brand-new Python release, and a source build needs a
# C++ toolchain. A missing compiler should never block the core project.
#
# Install after the core requirements:
#     pip install -r requirements-optional.txt
#
# If any single package fails, install the others individually - each is independent:
#     pip install lightgbm
#     pip install xgboost
#     pip install catboost
#     pip install shap

lightgbm>=4.3
